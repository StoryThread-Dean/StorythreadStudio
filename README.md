# StoryForge Project Scope

This folder contains the full project scope for **StoryForge**, a Windows desktop, local-first Markdown writing application for fiction and worldbuilding with context and content aware AI review tools.

## Included Files

- `01-product-scope.md`
- `02-architecture-and-storage.md`
- `03-profile-builder-spec.md`
- `04-ai-assistants-and-routing.md`
- `05-api-ui-and-data-models.md`
- `06-roadmap-and-mvp-plan.md`

## Intent

The project is designed around these rules:

- The writer does the majority of the writing.
- AI is used for review, refinement, analysis, brainstorming, and targeted suggestions.
- AI output is reviewed before use.
- Manual save only.
- No archival prose draft history in MVP beyond normal editor undo and redo.
- Markdown everywhere.
- AI must never use em dashes.
